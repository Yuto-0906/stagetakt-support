개인정보 처리방침

iPhone·iPad용 StageTakt와 이 지원 사이트의 정보 처리 방식을 설명합니다.

기기에 저장되는 음원과 라이브러리

가져온 음원，곡·세트리스트 설정은 앱 내부에 저장됩니다. PCM·파형·클릭·음성 카운트 캐시는 기기에서 생성합니다. 개발자는 음원과 라이브러리를 받지 않습니다.

영어 카운트인은 Apple의 기기 내 음성 합성을 사용합니다. 오프라인 사용 전 OS를 통한 음성 설치·다운로드가 필요할 수 있습니다. 앱은 음원을 음성 합성 서비스로 전송하지 않습니다.

선택적인 iCloud 동기화

동기화를 켜면 곡·세트리스트 정보와 원본 음원을 본인 Apple Account의 비공개 CloudKit 영역에 저장하고 다른 기기로 전송합니다. iCloud는 Apple이 운영하며 Apple의 약관과 개인정보 처리방침이 적용됩니다.

개발자는 별도의 라이브러리 서버를 운영하지 않으며 사용자의 비공개 라이브러리에 접근하는 기능을 제공하지 않습니다. 동기화를 꺼도 로컬과 iCloud 데이터는 유지됩니다.

구매

결제는 Apple이 처리합니다. 앱은 기기 내 StoreKit으로 Pro 구매를 검증·복원합니다. 개발자는 카드 정보를 받지 않으며 별도의 구매 검증 서버도 운영하지 않습니다.

구매 상태는 라이브러리와 iCloud 동기화 데이터에 포함되지 않습니다. 구매에 사용한 App Store Apple Account로 복원할 수 있습니다.

광고·분석·접근 권한

광고 SDK，외부 분석 SDK 또는 앱 간 추적을 사용하지 않습니다. 마이크·연락처·위치 정보 접근을 요청하지 않습니다.

표시 언어는 앱 설정에 저장합니다. 파일 정보는 가져오기 검증，오디오 캐시 및 동기화 무결성 확인에 사용합니다.

지원 이메일

직접 지원 이메일을 보내면 이메일 주소와 보낸 내용을 답변과 조사에 사용합니다. 자동 전송은 없습니다.

문의 기록은 대응과 관련 유지보수에 필요한 기간만 보관합니다. 삭제를 원하면 아래 주소로 연락해 주세요.

보관과 삭제

곡이나 세트리스트를 삭제하면 사용 중인 라이브러리와 동기화에 반영됩니다. 복구를 위해 원본 음원·백업·이전 동기화 기록이 남을 수 있으므로 곡 삭제가 모든 사본의 완전 삭제를 의미하지는 않습니다.

로컬 앱 데이터를 모두 지우려면 앱 정리 대신 앱 삭제를 사용해 주세요. iCloud 데이터는 모든 기기에서 동기화를 끈 후 Apple의 해당 앱 iCloud 저장 공간 관리 기능으로 삭제해 주세요. 따로 만든 내보내기 파일과 기기 백업은 개별 관리가 필요합니다.

이 사이트와 변경 사항

이 정적 사이트는 GitHub Pages에서 제공하며 분석·광고·외부 글꼴 스크립트를 사용하지 않습니다. GitHub는 자체 개인정보 처리방침에 따라 접근 로그를 처리할 수 있습니다.

정보 처리 방식이 바뀌면 이 방침을 업데이트합니다. 개인정보 관련 질문은 아래 StageTakt 개발자 문의 주소로 보내 주세요.
